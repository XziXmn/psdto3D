## 0. 背景（执行者必读，不要跳过）

被分析的软件是 **PSDTO3D 2022**（柱镜光栅立体印刷制版工具）。

它导出一张印刷 TIFF 分两步：

```
bmptotiff    把 N 个视图写成 C:\ok3dtemp\vwd001..NNN.gjs   （明文，合法 CMYK TIFF）
mergtotiff   读这些视图 -> 按柱镜参数交错 -> 写出成品 TIFF   （原来需要加密狗）
```

我们已经把 `mergtotiff` **重写**成一个替身 DLL（`cmyktiff2.dll`，63,229 字节），
无狗也能导出。目前和厂商有狗版本的差异是**逐像素平均 2.9%**，
怀疑是颜色通道（尤其 K 通道）的换算差异，需要对照数据确认。

## 2. 步骤 A：用原版（有狗）导出

1. 进入 `原版/`，双击 `psdto3d101.exe`
2. 菜单 `文件 → 打开工程文件`，选 `工程\测试工程.tw3d2`
3. 菜单 `文件 → 动画预览3D`（F9），等 13 个视图跑完
4. 菜单 `文件 → 停止预览`（F10）
5. 菜单 `文件 → 输出tiff`（Ctrl+E），存成 **`输出_原版.tif`**
6. **不要关程序**，先做步骤 A2

### A2：收集中间视图文件（关键）

导出会写出 13 个视图文件，路径在两个地方之一：

```
C:\ok3dtemp\vwd001.gjs  ...  vwd013.gjs
<工程目录>\ok3dtemp\vwd001.gjs ...
```

每个约 **11,907,334 字节**（1575×1890×4 + 334 字节头）。

**只需要 3 个**：`vwd001.gjs`、`vwd007.gjs`、`vwd013.gjs`
（如果 13 个都不大，全部拷走更好）

### A3：记录设置文件

```
<原版目录>\psdto3d104.inf
```
用记事本打开，把**第 2 行**原文抄下来（或整个文件拷走，只有几百字节）。

## 7. 我拿到之后做什么

1. **逐通道分解** `输出_原版.tif` 与 `输出_重写版.tif`：
   把 2.9% 拆成 C / M / Y / K 四项，确认差异集中在哪个通道
2. **对比两边的 `vwd*.gjs`**：
   如果视图数据本身就不同，说明差异在「视图生成」阶段而不是「交错」阶段
3. 按结论调整重写版的 `mergtotiff`：
   - 若是 K 通道换算 → 加一步墨量换算
   - 若是视图数据差异 → 转向视图生成那一段
4. 改完再让实机跑一次对照，收敛到逐像素一致或接近一致
