# PSDTO3D 重写规格（复刻蓝图）

> 建立：2026-11-17
> 目的：把逆向得到的原理、公式、数据结构整理成可直接照着实现的规格，
> 供后续重写与"对照修复老软件"使用。
>
> 标注：**[实测]** 已验证 / **[推导]** 由实测+原理推出 / **[待定]** 未验证

---

## 1. 软件在做什么（一句话）

把**分层 PSD**（每层带深度参数）转成**柱镜光栅立体印刷图**：

```
分层 PSD ──①视图生成──▶ N 个视角图像 ──②交错合成──▶ 印刷 TIFF
                                        └─ 也可输出 N 层 PSD（交后置软件做②）
```

* ① = PSDTO3D 的核心价值（老软件做这段）
* ② = `LenticularOmega` 做这段

## 2. 数据模型

### 2.1 工程文件（`.tw3d2` / `.gxwj`，GBK + CRLF）

| 行 | 内容 | 说明 |
|---|---|---|
| 1 | PSD 绝对路径 | 打开时按**文件基名**在工程目录查找 |
| 2 | `LPI Angles X Depth` | 见 2.2 |
| 3 | `99100 层数 宽 高` 或 `39550 0 0 0` | 魔数区分格式 |
| 4–6 | 厂商横幅 | 忽略 |
| 7 | 时间戳（`.gxwj` 额外一行浮点） | 忽略 |
| 8 | `DPI LPI2 计算值 flag1 flag2` | flag1∈{1,2} |
| 9 | 层数（仅 `.gxwj`） | |
| 10…9+N | **每层一个整数** | 深度，单位 = **1/10 柱镜**【实测】 |
| 10+N…9+2N | `<angle> <group> <scale>` | 每层：角度 / 深度分组 / 缩放 |
| 之后 | 手绘曲线块 | `<层> <组> <子序号> <点数>` + 坐标行 + 空行 |

> 注：实测 50 层的工程只写出 **48** 个整数（格式缺陷），解析时要按"读到不再是纯整数为止"，
> 且**不能假设与层一一对应**（缺的通常是前几层）。

### 2.2 界面参数（`立体设置` / `输出设置`）

| 面板 | 字段 | 本工程实测 |
|---|---|---|
| 立体设置 | LPI | 24 |
| | Angles（视图数 N） | 13 |
| | X | 1 |
| | Depth | 1 |
| 输出设置 | 打印 DPI | (Auto)/360…2880 |
| | 颜色模式 | 1bit×4 / Gray×4 / Color / 4bit |
| | 输出 DPI | 300…2400 |

## 3. 公式（全部）

### 3.1 柱镜几何

```
成品宽(in)      W_in  = 成品宽(cm) / 2.54
柱镜节距(px)    pitch = 视图宽(px) / (W_in × LPI)
柱镜数          n_lent = W_in × LPI
每柱镜像素      P     = 输出DPI / LPI          ← 印刷图上的像素/柱镜，常为小数
每视图像素      P/N
```

### 3.2 视图生成（①）【实测验证】

```
对于层 j、视图 k（k = 0..N-1）：

total_j = (int_j / 10) × scale_j × Depth × pitch        ← 该层总视差（px）
dx(j,k) = total_j × (k − (N−1)/2) / (N−1)               ← 第 k 个视图的水平位移

合成：由远及近（底层 → 顶层）alpha 叠加，每层先平移 dx(j,k)
```

**验证数据【实测】**（1114 工程：LPI 24 / N 13 / Depth 1 / pitch 12.70px）：

| 层参数 int×scale | 预测 total | 实测位移峰 |
|---|---|---|
| 30 × 1.0 | 38.10 | **38** |
| 25 × 1.0 | 31.75 | **31** |
| 15 × 1.0 | 19.05 | **18** |
| 10 × 1.0 | 12.70 | **12** |
| 5 × 1.0 | 6.35 | **7** |

> 五个峰全部命中，误差 ≤1px。**整数块单位 = 1/10 柱镜**已确认。

### 3.3 交错合成（②）

```
对输出列 x：
    l = floor((x + 0.5) / P)                 # 柱镜序号
    u = (x + 0.5)/P − l                      # 柱镜内位置 0..1
    view = min(N−1, floor(u × N))
    out[y][x] = view_img[view][y][x]
```

`P` 为小数时必须做**误差扩散**（等价于把 `P` 分摊成整数列宽数组
`lenticular_widths`，见 `LenticularOmega` 的 `compute_indices`）。

### 3.4 颜色

* 源 PSD 可为 RGB / CMYK
* 输出印刷图 = **CMYK 4 通道**
* 实测 2022 的交错代码里有墨量换算：
  ```
  out_ch = src_ch − (K_limit − 1) + ink_offset      # [ebp+0x44] / [ebp+0x48]
  ```
  具体阈值取自"打印 DPI/颜色模式"下拉，**待定**

## 4. 产物规格

### 4.1 印刷 TIFF

| 项 | 要求 |
|---|---|
| 色彩 | CMYK，8bit/通道 |
| 尺寸 | 成品尺寸(in) × 输出 DPI |
| DPI 元数据 | = 输出 DPI |
| 内容 | 已交错，单幅 |
| 压缩 | LZW / Deflate / 无 |
| **相位** | 第 0 柱镜中心 ↔ 第一组像素列中心，必须对齐 |

### 4.2 中间 PSD（给 `LenticularOmega`）

* N 个图层 = N 个视图，**图层名 view_01..view_NN**
* 全部同画布尺寸、不裁剪
* 层序 = 视图序（★ 已实现工具见 §6）
* 色彩：RGB 或 CMYK（与源一致）

| 模块 | 职责 | 备注 |

| `psdto3d101.exe` | 界面、工程解析、渲染调度、菜单 | 授权闸门 ×2、语言标志 |

| `8602.dll` | PSD 读写 | `readpsd` / `writepsd` |
| `ok3d4/ok3d1.dll` | `savetiff0` 写 TIFF | 含狗 |
| `zu6/zu06/dspr.dll` | 狗 SDK + 临时数据 | |
| `my32.dll` | USBKey SDK | |

**`mergtotiff` 内部结构**（RVA `0x7F720` 起，约 11KB）：

```
0x7F7A1  视图数 N = [obj_vtbl+0xC8]              → [-0x133]
0x7FAFA  循环 N 次：取每视图尺寸对 [obj+0x218]+0xC → [-0x1F4]
0x7FAAA  [-0x124]=300000, [-0x128]=300000（初值）
0x7FB3A  取 min → [-0x124], [-0x128]
0x7FBF1  ← 循环出口（本规格的插入点）
0x7F9BF  狗配置块：[-0x1A8/-0x1B0/-0x1B8] → [-0x10C]
0x7FE2C  [-0xFC] = 256（分块行数）
0x80BA7 / 0x81917 / 0x81B80 / 0x8201A / 0x82600 / 0x830E3
         ← 6 处通道数组分配：长度 [-0x133]，每块 GetMem([-0x124]*4*[-0xFC])
0x821ED  合成循环：读 channels[ch][row*[-0x124] + col]
```

## 7. 重写实现清单

### 7.1 模块划分

```
psd3d/
  project.py     读写 .tw3d2/.gxwj（含两种魔数、48/50 整数缺陷兼容）
  model.py       Layer(int, angle, group, scale)、Project(LPI, N, X, Depth, sheet)
  views.py       ① 视图生成（§3.2）
  interlace.py   ② 交错（§3.3，含 P 的误差扩散）
  color.py       RGB↔CMYK + ICC
  output.py      TIFF 写出（DPI 元数据 + 相位对齐）、PSD 写出（N 层）
  cli.py / gui.py
```

### 7.2 关键实现要点

1. **视图生成必须用 float 位移 + 高质量重采样**（老软件用整像素，会有 1px 抖动）
2. **交错必须支持小数 P**：用 `lenticular_widths` 误差扩散数组，不要硬取整
3. **相位对齐**要做成显式参数（`--phase 0..1`），否则不同批次印刷对不上
4. **CMYK 转换用 ICC**（FOGRA39 / JapanColor），不要裸公式
5. 大图必须**分块流式**（老软件 `[-0xFC]=256` 行一块就是这个思路）

### 7.3 验收方法

| 阶段 | 验收 |
|---|---|
| ① 视图生成 | 与老软件 `vw*.bmp` 逐像素比对（先比 vw1，再比 vw13） |
| ② 交错 | 与 `LenticularOmega` 输出比对 |
| 端到端 | 同一 PSD 两条管线出图，做 SSIM/PSNR |
