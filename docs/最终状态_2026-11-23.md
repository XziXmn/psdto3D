## 四、A6 的现状与走过的弯路（避免重复）

**已确认**：

1. `writepsd("C:\bio\out.psd","c:\ok3dtemp\",3000000,0,252000,0,11,4370,5197,3)`——参数正确；
2. 它会打开 `ly*/lyt*/vwd*/vwdt*`（22 个文件都在、都可读）；
3. PSD 文件上只有 1,305 次 1 字节写（头部 + 层记录），**没有任何大块写**；
4. 注入 `[ebp-0x14]/[ebp-0x18]` 后层矩形变成 `(0,0,5197,4370)`、通道长度 22,710,892（全对）；
5. **把 `vwd*.gjs` 换成合法 BMP 也没用** ⇒ 不是文件格式问题。

**已排除的手段**（不要再试）：

| 手段 | 结论 |
|---|---|
| 改 `cmyktiff2_real.dll` 的 TIFF 常量 | 无效（不在该路径上） |
| 删 `.enc.lll` 让它回退 `.enc` | 无效 |
| 换 `zu06.dll` 版本（2022 ↔ 10.1） | 无效 |
| 改 `zu06` 设备名（`MyUSBKey`） | 无效 |
| 给 `zu06/rip3d/ok3d1` 改 IAT（宽/窄/延迟） | **会导致进程中途退出**，已放弃 |
| 静态搜 UG 常量立即数 | 18 个二进制里全是 Delphi RTL 误报 |

**剩余最可能的原因**：PSD 参数来自 `readpsdpwph.enc.lll` 的解密结果（狗密钥），
本版程序为此做了 **768 次** `\\.\MyUSBKey#` 设备探测。
