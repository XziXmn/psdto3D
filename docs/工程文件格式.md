# PSDTO3D 工程文件（`.tw3d2`）格式与两版本兼容性

> 结论先说：**10.1 与 2022 用的是同一套文本工程格式，语法层面完全互通**。
> 用户看到的"工程文件互不通用"，来自三件事——工程里写死的 **PSD 绝对路径**、
> 工程与 PSD 的**成对绑定**（图层数/画布尺寸）、以及工程值越界后触发的
> 生成器崩溃（见 `故障诊断_浮点异常与AV.md`）。
> 本目录的工具可以无损读写、校正、并做跨版本迁移。

---

## 1. 文件性质

* 纯文本，**GBK 编码**，行分隔 `CRLF`；无二进制段、无压缩、无校验和。
* 扩展名 `*.tw3d2`（读取对话框的过滤器写的是 `tw3d2;tw3d`）。
* 12 个官方样本（两版本合计）全部可以被本工具 **逐字节无损回写**（`tw3d2.py roundtrip` → 12/12 identical），
  说明下列布局是完整且正确的。

## 3. 两个版本的实际差异

拿**同一个工程**分别用 10.1 与 2022 保存（`3d2.tw3d2`、`psdsampleCMYK.tw3d2`），逐行比对：

| 位置 | 10.1 | 2022 | 是否影响互读 |
|---|---|---|---|
| 行 2 的 LPI/Angles/X/Depth | `40.15 17 5` | `53 17 5` | 否，用户参数 |
| 行 8 的 flag2 | `1` | `8` | 否，解析器只当整数 |
| 曲线块的坐标内容 | 多出 `0 2 0 4`、`0 4 0 4` 这类块 | 以 `6 …` 为主 | 否，块表是"图层/分组/子序号"索引，两版语法一致 |
| 头部/图层段结构 | 完全相同 | 完全相同 | — |

另外两份样本（`3danimation.tw3d2`、`MorphZoomRatation.tw3d2`）在两版目录里**逐字节相同**（SHA256 一致），
这本身就说明格式没有被版本号锁死。

## 4. 真正让工程"打不开/崩"的三件事

1. **绝对路径**：所有官方样本的第 1 行都是厂商开发机的路径（`F:\d7\…`、`D:\Documents\guohongmin\…`），
   换机器就找不到 PSD。`tw3d2.py retarget --psd …` 一行命令即可修好；两个绿色包里我已经批量修过。
2. **工程与 PSD 成对绑定**：`layerCount`、`width`、`height` 都写在工程里，PSD 必须对得上。
   *实测*：`psdto3d2022绿色版\sample\3d2.psd` 是 **300×212**，而同名工程写的是 **600×424**
   —— 这个包里的 sample PSD 被替换过（文件日期 2023-03-05），所以打开 sample 工程必然报错。
   10.1 包里的 `3d2.psd` 是 **600×424**，与工程一致。
3. **PSD 图层规则**：程序要求所有图层都是"普通层"，不能有背景层（`Background`）。
   触发时弹 `All layers must be simple layer, Can not have backgroup layer!`，
   随后带着未初始化的图层数组继续跑，就会走到浮点异常与 `0x50A001` 的空指针崩溃。

## 5. 工具

```powershell
# 看工程头/参数/问题
python tools\tw3d2.py dump  "...\sample\3d2.tw3d2"

# 批量体检（含与 PSD 头比对：图层数、画布尺寸）
python tools\tw3d2.py check "...\sample\*.tw3d2" --psd     # 直接列文件即可

# 无损性自检（解析→回写 是否逐字节一致）
python tools\tw3d2.py roundtrip ...\*.tw3d2

# 换 PSD 路径 / 修 layerCount / 修 Angles
python tools\tw3d2.py retarget "工程.tw3d2" --psd "D:\work\a.psd" --out "工程_便携.tw3d2"
python tools\tw3d2.py retarget "工程.tw3d2" --psd "a.psd" --angles 7 --fix-counts

# PSD 头信息（尺寸/通道/位深/图层数）
python tools\psdinfo.py "a.psd"

# 把一个包内所有 sample 工程的 PSD 路径改成包内同名 PSD
python tools\fix_sample_projects.py "psdto3d2022绿色版"
```

写回策略：**只改必要的表头行**（第 1/2/3/8 行），其余行原样保留，
因此修复不会破坏图层段与手绘曲线段（`roundtrip` 12/12 逐字节一致即为证）。

## 6. 跨版本互读的操作建议

* 把工程与它的 PSD 放在同一目录，用 `retarget` 改成包内路径 → 两版都能打开。
* 打开前先 `check --psd`：图层数、画布尺寸不一致就先别开，必定出问题。
* 从 10.1 迁到 2022（或反向）：直接改路径即可，**不需要转换格式**；
  如果 PSD 也被换过，先用原 PSD 打开一次、让程序自己重建工程，再迁移。
* `Angles` 保持 > 0（默认 7 最稳），可以规避已知的除零崩溃。
