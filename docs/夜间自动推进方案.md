# 夜间自动推进方案

> 目标：在无狗环境下让 `Psdto3d 2022` 的导入结果与真狗基准完全一致（Offset 五点 −5、cm 五点 −0.04）。
> 本文件是自动执行的作业单：每一步都有明确的动作、判据和放弃条件。

---

## 零、不可违反的约束

1. 原始 `Psdto3d\` 目录**不得修改**；所有实验在 `_work\*` 下新建目录。
2. 判据只用「网格写入的实际参数」和「真狗基准表」，不用工程变体、不改角度、不改 `psdto3d104.inf`。
3. 每次改 exe 前先备份，改完立刻跑一次验证（`hwbp32.exe` + 单地址断点）。
4. 单次运行上限 150 秒；连续两次 AV>5 说明改坏了，立即回退。
5. 断点工具限制：`exec@A,B` 双地址不可靠，**只用单地址**；读栈上字符串用 `[esp+4]`。

---

## 一、已确认的事实（不要再重复验证）

| 项 | 结论 |
|---|---|
| 狗的作用 | 只做放行判定；`0x4D2F14` 把 8 个参数**原样拷回**，不提供数字 |
| 无狗分支 | `0x4E32FC` 返回 `.lll` 的长度字段（34）→ 判定失败 |
| 让判定通过 | 改 `0x4E33EE` 的 `movsx eax,word[ebp-0x16]` → `xor eax,eax`（v5 已做，AV=0） |
| 层数来源 | **DLL 在导入 PSD 后写入** `0x52315C`，值 32（写断点已证实，写入点 `0x04FD2CBB/0x4FD2D85`） |
| Offset 列 | `_work\v2` 已正确（五行 17 字符值）；v2 靠桩设置层数/计数 |
| cm 列 | 从未写入；cm 在 `0x513AAA` 因 `[ebp-8]==0`（网格格为 nil）退出 |
| 网格存储 | 惰性初始化在 `0x48D408`，容器字段 `[grid+0x2D8]`，增长门限 `[grid+0x21C] > 0x200` |
| 网格写入 | 装载器只写列 1（Group）和列 2（Offset），**从不写列 3** |

## 二、作业单（按顺序执行，做不通就跳到下一个）

### 任务 A：确认网格初始化是否执行

**动作**：用 v5，在 `0x48D408` 下断点跑一次导入。
**判据**：
- 命中 → 存储已初始化，问题在别处，跳到任务 C；
- 不命中 → 进入任务 B。

### 任务 B：强制初始化网格存储

**动作**：在 v5 的 `0x511912`（解析调用点）前插入调用 `0x48D408(grid)`。
桩写法：

```
mov eax,[ebp-4]
mov eax,[eax+0x30C]
call 0x48D408
（随后执行原来的 call 0x4D2F14，即跳回 0x511912 的下一条）
```

**判据**：跑一次看 `0x48D628` 的列分布是否出现 `col=3`。
- 出现 → 进入任务 E（验证数值）；
- 仍无 → 跳到任务 C。

### 任务 C：cm 的第一次读为什么是 nil

**动作**：在 `0x513AAA` 下断点，记录 `[ebp-8]`、`[0x52315C]`、`ebx`（此时 ebx=Self）。
**判据**：
- `[0x52315C]` 不是 32 → 说明 DLL 写入在我们流程里没生效，改为在桩里显式写入 32，再试；
- 是 32 但 `[ebp-8]=0` → 网格第 32 行确实为空，进入任务 D。

### 任务 D：绕开网格，直接写第 3 列

**动作**：在 Offset 写入循环之后（`0x511AFA`，已确认会执行），用桩调用网格 setter：

```
; 形参：eax=网格, edx=3(列), ecx=行, 栈=字符串指针
; 值 = Offset 值 × 0.008，可用 0x40B134 把 Extended 转成字符串
```

按 cm 内部的写法（`0x513B9C..0x513BD2`）照抄，只去掉所有判定。
**判据**：`col=3` 出现且五行是 `-0.04`。
- 成功 → 进入任务 E；
- 连续 2 次失败 → 停止，记录到 `docs/夜间结果.md`。

### 任务 E：验收

**动作**：完整跑一次（菜单 7 → 菜单 10），记录：
- `0x511A73` 的 32 次写入中，五行是否 17 字符值；
- `0x48D628` 的 `col=3` 是否有五个 `-0.04`；
- AV 数是否为 0。

**判据**：三项全对 → 达成目标，写 `docs/夜间结果.md` 并在最后一条消息里报告。

## 三、停止条件

满足任一即停并在 `docs/夜间结果.md` 记录：

1. 任务 E 全部通过（成功）；
2. 任务 D 连续 2 次失败；
3. 同一任务累计尝试超过 6 次仍未前进；
4. 连续两次运行出现 AV>5 且回退后仍复现。

## 五、已知可用的地址

| 地址 | 含义 |
|---|---|
| `0x511912` | 装载器调用解析的位置 |
| `0x511A73` | 写 Offset 列（列 2）的 setter 调用点 |
| `0x511AFA` | Offset 循环之后的跳转（确认会执行） |
| `0x48D628` | 网格 setter（eax=grid, edx=列, ecx=行, 栈=串） |
| `0x48D5B8` | 网格 getter（同上，栈=&out） |
| `0x48D408` | 网格存储惰性初始化 |
| `0x513A30` | cm 函数 |
| `0x513AAA` | cm 的第一个空值判定 |
| `0x513B3E` | cm 的正式计算入口 |
| `0x513B9C..0x513BD2` | cm 内部「计算→格式化→写列 3」的完整序列 |
| `0x4E33EE` | 无狗分支返回值（v5 已改为 0） |
| `0x52315C` | 层数（DLL 写入） |
| `0x523190` | 倍率相关（18000） |
| `0x523074` | 倍率相关（25400×计数） |
| `0x5232F4` | cm 使用的 g4（目标 80） |
