工具说明（工具\ 目录）
=====================================

一、转换 99 版工程（.gxwj）→ 10.1/2022 工程（.tw3d2）
--------------------------------------------------
99 版工程的文件标记是 39550，10.1/2022 是 99100；两者都是 GBK 纯文本、CRLF 分隔，
差别只在头部几行（99 少"作者/保存时间"两行、多一行数值，标记行里的层数/宽高是 0）。

用法（需要本机装有 Python 3）：
    工具\转换99工程.cmd  旧工程.gxwj  新工程.tw3d2  该工程用的psd

或者命令行：
    python 工具\gxwj2tw3d2.py 旧工程.gxwj 新工程.tw3d2 --psd 该工程用的psd

要点：
  * 层数 / 宽 / 高 会从 PSD 头部读出来写进第 3 行（99 工程里这三项是 0，没法用）；
  * 第 1 行会自动改成你给的 PSD 路径（99 工程里通常是作者机器的绝对路径）；
  * 其余内容（LPI/角度/景深/每层数值/角度表/手绘曲线）逐字节原样搬过去。

二、反向工具（10.1 → 99）
--------------------------
     python 工具\tw3d2_2gxwj.py 输入.tw3d2 输出.gxwj

主要用于验证转换是否正确：10.1 → 99 → 10.1 回转后，
除"作者/保存时间"两行外应与原文件**逐字节一致**（本机实测 356/356 行一致）。

三、PSD 结构查看
----------------
     python 工具\psdinfo.py 某某.psd

输出：尺寸 / 位深 / 通道数 / 颜色模式 / 图层数，用于核对工程第 3 行是否与 PSD 一致。

四、已知限制
------------
* 10.1 的导入器对 PSD 比较挑：实测 **5 通道（CMYK+Alpha）的 PSD 会直接崩**
  （Access violation in Button8Click），与工程格式无关；这种情况请先在 Photoshop
  里合并/转成 RGB 8 位 3 通道再导入。
* 官方 CMYK 样本（psdsampleCMYK.psd）在本机导入会报 Invalid floating point operation，
  原因同上：导入器对颜色模式敏感，不是工程转换的问题。
* 转换只处理工程文件；PSD 本身必须自己准备好，且图层数/尺寸要与 PSD 实际一致。
